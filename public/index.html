Why Teagram

Host it yourself

The server, the web client and the Mac app are all open source on GitHub. Run the server and the web client on a machine you control, and point Teagram for Mac at your server's address.

Keep it private

On your own server, your chats, files and account are stored on a machine you control, not a company's. Messages aren't end-to-end encrypted, so whoever runs the server can read them, and on your own server that's you.

Just a username

People find you by your username, and the name they see is up to you. Teagram never asks for a phone number, and an email is optional. See what a server keeps.

The features you're used to

Teagram speaks the Telegram protocol, and its apps are built on the open-source Telegram apps. One-to-one chats, groups, channels, photos and files, reactions, polls, folders and search are all there.

Frequently asked questions

What is Teagram?

Teagram is a messaging app for one-to-one chats, groups and channels, with an open-source server you can run yourself. You sign up with a username and a password instead of a phone number.

How is Teagram related to Telegram?

Teagram speaks the Telegram protocol, the language its apps and server use to talk to each other. Teagram for Mac is based on Telegram Desktop and Teagram Web on Telegram Web K, both open source. Teagram has its own servers and accounts, so you can't message Telegram users from it. Teagram is not affiliated with Telegram.

How private is Teagram?

As private as the server you use, and the most private one is your own: run it yourself and everything it stores is on machines you control. Messages are encrypted between your app and the server but not end to end, so whoever runs the server can read them. You sign up with a username and a password, no phone number or email, and the password itself is never sent to the server.

What does a Teagram server keep about me?

Your username, profile, chats and files. For each signed-in session, its IP address, device, system and app version, which you can see and end in your list of sessions. A recovery email only if you add one, and short-lived counters per network that limit abuse such as password guessing. A server's operator can also turn on a Cloudflare check at sign-up, which shares your IP address with Cloudflare.

How much does Teagram cost?

Nothing. Teagram is free and open source. If you run your own server, the only cost is the machine it runs on.

How do I get an account?

Accounts live on a Teagram server. Open Teagram for Mac, enter your server's address, then pick a username and password. No server yet? Run your own with Teagram Server, or wait for Teagram Web, coming soon.

How do I open Teagram for Mac the first time?

Teagram for Mac isn't notarized by Apple, so macOS stops it the first time you open it. Go to System Settings > Privacy & Security, choose Open Anyway next to the message about Teagram, and confirm. After that, it opens like any other app.

Is there an app for iPhone, Android, Windows or Linux?

No. Teagram for Mac is the only app. Teagram Web, coming soon, runs in the browser on other devices.
